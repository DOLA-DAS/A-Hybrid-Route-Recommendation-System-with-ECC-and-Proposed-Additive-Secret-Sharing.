This project implements a secure multi-criteria decision-making framework combining ECC ElGamal encryption, additive secret sharing, pseudonymous authentication, and TOPSIS ranking.

**Features-**
ECC-ElGamal encryption with re-encryption and threshold decryption
Newly proposed Additive secret sharing for secure data protection
Token-based pseudonymous authentication
Dynamic pseudonym generation for anonymity
SHA-256 based data binding and verification
Blind-weight TOPSIS decision-making
Entropy-based objective weight calculation
